# Gym Buddies Alpha Tester Instructions

Thank you for testing Gym Buddies. The goal is to find confusing, broken, repetitive, unfair, or especially enjoyable moments in the existing game.

## Before starting

1. Open the supplied GitHub Pages link in a normal browser tab.
2. If desired, select **Alpha Playtest** at the lower-right corner.
3. Read the privacy summary and choose **Enable Alpha Playtest Mode**.
4. Optionally select cohort labels that you choose for yourself.
5. Do not put your real name, email, location, or contact details in a note.

Alpha Playtest Mode is optional. It stores a bounded report only in your browser and never sends it automatically.

## Suggested session

Play for 30–45 minutes. Explore naturally and avoid looking for a “correct” solution.

Try to:

1. Start a new journey.
2. Create a trainer.
3. Complete the first workout.
4. Travel to the first route.
5. Trigger an encounter.
6. Attempt a capture.
7. Customize a Buddy.
8. Use recovery.
9. Attempt a boss challenge.
10. Close and reopen the game.
11. Try one alternative control method when available.
12. Submit or export feedback.

It is useful if something fails. Note what you expected, what happened, and whether it happens again.

## Giving feedback

Use the fixed **Playtest Note** button for:

- bug;
- confusing;
- too difficult or too easy;
- repetitive;
- visual, control, performance, or save issue;
- something you liked.

The game attaches only coarse gameplay context. Writing a note is optional. Milestone prompts are brief, optional, and may be skipped.

## Exporting

1. Open **Playtest Note**.
2. Expand **Report preview and export**.
3. Review what will be included.
4. Remove any note you do not want to share.
5. Uncheck environment details or timeline if desired.
6. Select **Export JSON report**.
7. Send the downloaded file only through the channel supplied by the test organizer.

The filename starts with `gym-buddies-playtest-`. Do not send your Gym Buddies save file unless a developer separately requests it and explains why.

## Good bug notes

Include the action, expected behavior, observed behavior, and whether it repeated. A screenshot is helpful for visual problems. Avoid subjective fixes such as “make it easier”; describe the point where the requirement or consequence became unclear.

## If the game crashes

Use the recovery controls first. If Playtest Mode was enabled, the exported report will contain a safe error category and recent bounded events. Your game save is not deleted to create the report.
