# Gym Buddies Showcase Pose Standard

## Resolution and purpose

Showcase art uses 64×64 logical RGBA frames. This tier is reserved for Buddy
customization, Physique Review, bodybuilding challenges, major boss cards, and
other deliberate inspection surfaces. Compact party and menu UI must use the
32×32 tier instead.

## Pose order

Every showcase row contains:

1. `front-relaxed`
2. `back-relaxed`
3. `front-double-biceps`
4. `back-double-biceps`
5. `side-chest`
6. `side-triceps`
7. `most-muscular`
8. `abs-and-thigh`
9. `victory-pose`
10. `fatigue-pose`

These labels describe fictional, tasteful game poses. They are not medical or
real-world physique assessments.

## Species adaptation

- Bramblift shows strength through shoulder shelf, forelimb density, planted
  legs, and grappler posture.
- Rivetjack uses back taper, athletic haunches, long forelimb lines, and tail
  counterbalance.
- Prismantle translates poses into diamond-core compression, fin spread,
  crest direction, facet tension, and asymmetric wing rhythm.
- Mat Watchman preserves Bramblift anatomy while adding tier-specific harness,
  wraps, belt, halo, breath, and arena-light accents.

Species without human anatomy must never receive pasted-on human muscle
shapes. A front-double-biceps equivalent may use paired fins, wings, horns,
shell plates, or limb braces while preserving the named presentation beat.

## Boss rows

Tiered showcase sheets use the same five-row order as battle sheets. The
selected tier changes presentation but not profile IDs, cosmetics, stats, or
save data.

## Acceptance

- every pose is authored at 64×64 rather than stretched from 24×24;
- front and back poses emphasize different anatomy;
- side poses retain readable depth;
- physique presets and cosmetics remain visually consistent with overworld and
  battle contexts;
- safe border, pivot, and ground line remain valid;
- mobile CSS displays the canvas without fractional logical scaling;
- showcase files are not fetched or decoded before a showcase surface opens.
